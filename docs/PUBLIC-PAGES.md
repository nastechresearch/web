# Public page architecture

The public app now exposes **300 source-mapped surfaces** through its in-app explorer. Each page keeps a direct link to the relevant NasTech documentation or repository source, while the static export adds a fallback document so deep links load the corresponding application view on GitHub Pages.

| Surface family | Purpose |
|---|---|
| Core system and operating model | Product overview, architecture, installation, gateway, provider, and research paths. |
| Capability atlas | One surface for every documented capability card. |
| Focus details | Nested views for configuration, install paths, automation, accessibility, and expansion areas. |
| Workspaces | App-oriented pages for developer, agent, research, automation, provider, deployment, community, and Africa-forward work. |
| Operations | Guided surfaces for safe use, maintenance, learning, release work, and launch preparation. |

All source-backed claims should remain linked to the official NasTech Agent documentation or repository.
