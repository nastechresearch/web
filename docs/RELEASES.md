# Release information

This repository publishes a public NasTech web build. The automated scanner records the upstream NasTech Agent revision and latest published upstream release in [upstream-status.md](./upstream-status.md) only when that source revision changes.

## Release checklist

1. Review the completed quality workflow.
2. Verify the Pages deployment result.
3. Review the upstream revision and release metadata.
4. Add human release notes for changes that alter user-visible behavior.

## Versioning policy

Use descriptive, NasTech-focused release titles. Avoid platform-specific implementation names in public release text.
